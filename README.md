# 📄 QueryDoc — RAG Document Q&A System

</summary>

### Overview

QueryDoc is a Retrieval-Augmented Generation (RAG) application that enables users to upload PDF documents and ask natural-language questions. Instead of relying solely on an LLM's memory, the system retrieves relevant document chunks using semantic search and generates grounded, source-aware responses.
